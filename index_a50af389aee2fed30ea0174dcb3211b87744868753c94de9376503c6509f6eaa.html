11

ESD-Station

Development of an automated ESD test station designed to improve traceability and compliance within the laboratory environment.

The system required every employee entering the lab to authenticate using their NFC badge before performing an ESD shoe test. Test results were automatically recorded and linked to the corresponding user, enabling digital logging and reducing manual documentation effort. 

The project included hardware integration, embedded communication, backend data handling, and user interface development for reliable daily operation in an industrial environment. The focus was placed on automation, usability, and compliance with ESD safety procedures.

Key aspects included automated data acquisition, signal analysis, and result visualization for efficient optical system characterization.
